# Social Protection Services Support Guide — Jamaica

This repository is the public GitHub Pages entry point for the project. The landing page forwards the owner to the private review copy.

The supplied booklet was marked confidential and not for sharing. Its chapter content, programme details, and contacts are therefore kept in the owner-only review site, not in this public repository. The current GitHub Pages view contains no booklet details.

## Private review copy

Open the owner-only Social Protection Services Finder site from the GitHub Pages entry page. Sign in with the account that owns the site if prompted.

## Repository contents

- `index.html` — safe handoff page to the owner-only review site
- `assets/` — initial public concept shell assets, retained for reference
- `data/services.json` — empty service data schema; no booklet records are published

The private review site contains the combined About/Home landing page, six chapter views, searchable programme and contact listings, the document reference, referral procedures, and the Jamaica parish map. Those draft entries are labeled for verification.
