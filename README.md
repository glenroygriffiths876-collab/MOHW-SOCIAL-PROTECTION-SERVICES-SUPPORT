# Social Protection Services Support Guide — Jamaica

Interactive website for the Social Protection Services Support Guide. The Home experience and Chapter One are combined. Navigation follows the guide’s six chapters, with the Jamaica parish map available through Find Services.

## Site features

- Referral Procedures: six-step referral pathway
- Programme Directory: searchable programme profiles
- By Category: support groups, benefits and target groups
- Decision Guide: search situations and related services
- Contact Directory: searchable agency contacts and quick contacts
- Find Services: parish map with support filters and search
- Documents to Apply: document, requirement, process and cost reference

## Content status

The site is populated from the November 2026 working guide. Programme information, eligibility statements, costs, contacts and hotlines are presented as draft content and require confirmation with the responsible agencies before operational use. The map supports parish-based browsing and does not claim verified facility coordinates.

No personal data is collected and the site does not make eligibility decisions or submit referrals.

## Run locally

Serve the repository root with any static web server, then open `index.html`. The site loads `data/guide-content.json` at runtime.
