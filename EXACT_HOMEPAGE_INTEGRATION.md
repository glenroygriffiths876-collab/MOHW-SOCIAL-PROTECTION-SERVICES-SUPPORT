# Exact screenshot home integration

Required binary files:
- assets/mohw-homepage-exact.png — the user's 1448x1086 approved PNG
- assets/gia-introduction.mp4 — the user's 32-second approved MP4

Transparent, keyboard-focusable hit targets wire image positions to existing native navigation, GIA, search, sharing, reporting, feedback and accessibility. Video plays in an HTML5 player in the artwork's Gia window. The other application pages and existing guide data are unchanged.

IMPORTANT: If the original image is absent the site continues using its previous working homepage. If the MP4 is absent the picture remains visible and an Ask GIA fallback appears. These media are not yet in the repository and must be uploaded as real binary assets, not base64 text or temporary CDN previews.

Mobile and high-contrast views retain the pre-existing native responsive homepage.
