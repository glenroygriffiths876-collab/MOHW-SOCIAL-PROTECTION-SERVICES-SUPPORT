# Content review status

The site now contains the November 2026 working guide content, entered for review after public-release approval.

Before using this as an operational referral directory, verify with the responsible agencies:

- Programme names, target groups, eligibility wording, benefits and application processes
- Document requirements, fees and costs
- Contact numbers, addresses, email addresses, websites and hotlines
- Parish-level availability and local referral routes
- Urgent-safety and safeguarding wording

The parish map is for browsing by parish. It does not show verified service-facility coordinates. Do not interpret an empty search as evidence that a service is unavailable.

The content is a transcription of the supplied draft and has not been independently validated.
## GIA 2.0 implementation notes (15 November 2026)

The new guided referral assistant supports needs matching, agency preparation, service-specific document lists, reviewed WhatsApp click-to-chat with caller-entered recipient phone and location, map searches or user-supplied confirmed Maps links, and copy/print follow-up drafts. It does not send messages by itself, store client records, schedule reminders, verify appointment availability, or provide human-generated answers from a server-side language model. These should not be represented as operational capabilities.

The published emergency quick-contact code now uses 119 for police and 110 for fire/ambulance, as independently checked against JCF and MOHW official sources; this corrects the emergency-ambulance value in the source draft. All other contacts and programme eligibility details remain as written in the source guide pending agency review.

The 14-parish map is not a verified directory of agency coordinates. GIA's fallback Google Maps link is an explicit search query; a worker may paste a confirmed destination link.
